# 블로그 작업실 v0.2

사진·방문 메모 → 키워드 후보·제목·목차 → 내 말투의 본문 → 검수·저장으로 이어지는 로컬 프로그램입니다.
Python 3.11 이상이 필요합니다. 매장 조사·엔서포터 자동 분석에는 Selenium과 Chrome이 필요합니다.

## 실행

1. ZIP을 새 폴더에 풀고 `start.bat`를 더블클릭합니다. Mac/Linux에서는 `python3 app.py`.
2. 브라우저에서 http://127.0.0.1:8765 가 열립니다. 프로그램 창은 켜두세요.
3. '글을 생성할 AI'에서 실행 방식을 고르고 '실행 방식·말투 저장'을 누릅니다.
4. 사진 또는 사진 폴더, 가게 이름·방문 메모를 입력합니다.
5. 필요하면 목표 키워드와 조사 자료(출처·기준일 포함)를 입력합니다.
6. 초안을 생성하고 키워드 후보·목차·제목·본문·사진 배치를 검수합니다.
7. 본문을 직접 수정하거나 수정 요청으로 재생성합니다. 초안을 저장하거나 사진 포함 HTML을 내려받습니다.

## AI 실행 방식

### Codex CLI

본인 PC에 Codex CLI가 설치되어 있고 터미널에서 `codex` 실행 및 로그인이 완료되어 있어야 합니다.
프로그램은 `codex exec`에 사진과 작성 지침을 전달하고 최종 응답을 받습니다.
읽기 전용 샌드박스를 사용하며 별도 API 키를 요구하지 않습니다.
로그인 계정·버전·사용 한도에 따라 실행이 실패할 수 있습니다. 무료·무제한을 뜻하지 않습니다.

### Claude Code CLI

본인 PC에 Claude Code가 설치되어 있고 터미널에서 `claude` 실행 및 로그인이 완료되어 있어야 합니다.
`--restricted`를 지원하는 버전(v2.1.248 이상)이 필요합니다.
임시 사진 폴더에서 Read 도구만 사용하도록 호출합니다. 쉘·편집·MCP 도구는 허용하지 않습니다.
임시 폴더 안의 사진을 읽고 JSON 본문을 반환하도록 요청합니다.
v2.1.305에서 사진 없는 텍스트 생성을 확인했고, 2026-10-22에는 Claude 경로의 실제 사진 13장 포함 생성도 확인했습니다.
v2.1.241 이하는 `--restricted` 미지원으로 실행이 실패합니다. `claude update`로 업데이트하세요.

두 CLI 방식 모두 사진·메모·말투 예시를 선택한 서비스로 전달합니다.
프로그램에서 API 방식용 키를 CLI에 넘기지 않도록 주요 API 키 환경변수를 제거한 별도 환경으로 실행합니다.
API로 자동 전환하지 않습니다. CLI에 저장된 인증·조직 설정 및 사용 한도·과금 정책이 적용됩니다.
CLI 설치·로그인 방법은 각 공식 문서를 참고하세요.

- Codex: https://developers.openai.com/codex/noninteractive
- Claude Code: https://code.claude.com/docs/en/headless

### Claude API (선택)

`config.example.json`을 복사하여 같은 폴더에 `config.json`으로 저장합니다.
`api_key`에 Anthropic API 키, `model`에 계정에서 사용 가능한 이미지 입력 지원 Claude 모델 ID를 입력하고 다시 실행합니다.
환경변수 ANTHROPIC_API_KEY / ANTHROPIC_MODEL도 지원합니다. API 사용료는 별도입니다.
키는 화면에 표시하지 않습니다. config.json은 평문이므로 본인 PC에서만 보관하고 채팅·공유 파일에 넣지 마세요.

## 저장된 말투 = 프롬프트·예시 적용

- 말투 유형과 기존 글 1~3편을 저장하면 매번 자동으로 전달합니다.
- 참고 글에서 문장 길이·어미·문단 구성을 적용하고 장소·경험은 가져오지 않도록 지시합니다.
- 모델 가중치를 바꾸는 파인튜닝은 하지 않습니다.
- 키워드 후보는 AI 아이디어입니다. 실제 검색량·경쟁도·인기를 자동 조회하는 기능은 없습니다.
- 검색광고 키워드도구에서 확인한 자료를 직접 입력하면 그 자료를 바탕으로 작성하도록 요청합니다.
- 제목·목차·말투 점검은 한 번의 생성 안에서 요청합니다. 별도 조사·검수 모델을 따로 실행하지 않습니다.
- 유행 추적·검색 상위 노출·수익 보장 기능은 없습니다.

## 사진과 초안

- 사진은 최대 20장. JPG·PNG·WebP 지원. HEIC는 JPG로 변환해 주세요.
- 브라우저가 긴 변 1600px 이하 JPEG로 변환합니다. 원본 파일은 수정하지 않습니다.
- 설정·초안·축소 사진은 `data/studio.sqlite3`에 저장됩니다. 이 파일을 백업하세요.
- 초안 생성 성공 시 자동 저장하고 다시 열 수 있습니다. 재생성·수동 저장은 현재 초안을 덮어씁니다. 수정 이력 기능은 없습니다.
- 최종 게시와 사실 확인은 직접 합니다. 네이버 자동 입력·게시와 폴더 자동 감시·예약 실행은 아직 없습니다.

실제 연결은 Claude Code CLI v2.1.305에서 사진 없는 텍스트 생성 1회를 확인했습니다 (2026-10-21).
사진 포함 생성, Codex CLI(미설치), 화면 클릭·시각 검증은 아직 확인하지 못했습니다.

아래는 엔서포터 전환 전의 과거 API 경로 설명입니다. 현재 기본 흐름은 아래 엔서포터·플레이스 사용 절을 따릅니다. 당시에는 입력 화면의 자동 분석을 선택하면 공식 API로 검색하고 최대 3개 글의 본문을 분석합니다. 단어 빈도·등장 글 수·정보 항목 추정 순서를 표시하며, 말투는 내 설정만 적용합니다. 검색량이나 상위 노출 점수가 아닙니다. 수집 실패 시 사진·메모로 작성을 계속합니다. 실제 AI 포함 생성과 화면 확인은 추가 검증이 필요합니다.
`python tools/verify_collect.py "검색어"` — 실제 네트워크로 검색·본문 추출을 시험하고 결과를 `tools/verify_collect_result.json`에 남깁니다.
신규 키는 NAVER API HUB에서 블로그 API를 등록해 발급받습니다. `naver.example.json`을 `naver.local.json`으로 복사한 뒤 `client_id`, `client_secret`을 입력하세요(이미 파일이 있으면 직접 수정). 환경변수 NAVER_CLIENT_ID / NAVER_CLIENT_SECRET이 있으면 파일보다 우선합니다. YAML이나 추가 패키지는 필요 없습니다. `naver.local.json`은 Git 제외 대상이며 공유하지 마세요.
기본 검증은 공식 블로그 검색 API만 호출합니다. 본문 추출 시험까지 하려면 `python tools/verify_collect.py "검색어" --with-bodies`를 사용하세요. 과거 검색 HTML·DuckDuckGo 검증 경로는 실행하지 않습니다. 검색어 트렌드는 아직 연결하지 않았습니다.
검증 결과와 수집 경로별 판단은 REQUIREMENTS.md 3장을 참고하세요.

다른 가이드의 비공개 프롬프트는 포함하지 않았습니다. 이 프로그램의 작성 지침은 별도로 작성했습니다.


## 엔서포터 자동 분석 사용 (2026-10-22)

현재 앱의 자동 분석은 블로그 API 대신 엔서포터가 설치된 별도 Chrome을 사용합니다.

1. Selenium이 없다면 `python -m pip install selenium`을 실행합니다.
2. **최초 1회만** `python tools/probe_nsupporter.py setup`으로 전용 Chrome을 열고 엔서포터를 설치합니다. 이후에는 전용 Chrome을 켜 둘 필요가 없습니다. 매장 조사·엔서포터 분석을 실행할 때 닫혀 있으면 **같은 프로필로 자동 실행**되고(설치·로그인 유지), 열려 있으면 재사용합니다. 설치 페이지를 다시 열거나 재설치를 요구하지 않습니다.
3. 앱을 실행하고 ‘엔서포터 자동 검색·키워드 분석’을 선택해 생성합니다. 전용 창은 필요할 때 자동으로 열립니다.
4. 검색은 두 가지 목적으로 분리해 실행합니다. 검색 탭은 작업 중 직접 조작하지 마세요.
   - **같은 매장 글 분석**: 입력한 가게 이름 그대로 검색합니다. 지역·정확한 상호·지점까지 적을수록 정확합니다(예: `신림 올바른 숙성회`).
   - **목표 키워드 글 분석**: 목표 키워드 입력란에 쉼표 또는 줄바꿈으로 구분해 적습니다. 최대 3개까지 각각 따로 검색하고, 초과분은 건너뛰고 알려줍니다.
5. 검색마다 분석 가능한 글을 최대 3개 채택합니다. 제목과 엔서포터의 검색어 등장 횟수로 관련도를 판정해 `관련 확인`/`불확실`/`제외`로 표시하고, 제외된 글(검색어 단어 미확인)은 집계에서 뺍니다. 같은 글이 여러 검색에 나오면 한 번만 분석하고 재사용 표시를 합니다.
6. 초안 화면의 ‘참고 글 키워드·구성 분석’에서 검색 목적·검색어·선정 글 제목/URL·판정 이유·성공/실패·수집 시각을 확인할 수 있습니다. 이 내용은 초안과 함께 저장됩니다.

엔서포터가 제공하는 항목은 글자 수(전체/한글/영어/숫자), 검색 키워드 등장 횟수, 단어별 사용 횟수, 외부링크 수입니다. 사진 수·제목 분석·소제목·글 구성은 제공되지 않아 표시하지 않습니다.
말투는 내 설정·내 글 예시만 적용합니다. 단어 빈도는 검색량·경쟁도·추천 반복 횟수가 아니고, 검색 결과 전체나 네이버 최상단 순위를 대표하지 않습니다. 일부 검색이 실패해도 확보한 자료와 사진·메모로 생성을 계속하며, 유료 API로 자동 전환하지 않습니다. 이 경로에서는 네이버 API 키가 필요하지 않습니다. 브라우저 자동화는 확장·네이버 화면 변경이나 차단으로 실패할 수 있습니다.

검증 상태(2026-10-22): 모의 테스트 33건 통과. 실제 연결은 `신림 올바른 숙성회`(매장 3/3 관련 확인) + `신림 혼술`(3건, 불확실 1건 포함) 수집, Codex 텍스트 생성, **Claude 경로의 실사진 13장 포함 생성**까지 확인했습니다. 화면 클릭 검증은 아직 하지 않았습니다.

## 매장 정보 자동 조사 (2026-10-22)

- 가게 이름(지역·상호·지점까지)을 넣고 생성하면 네이버 플레이스 화면에서 **보이는 값만** 자동 조사합니다: 매장명, 주소, 현재 영업 상태·라스트오더, 요일별 영업시간, 전화, 주차, 공개 메뉴·가격, 지도 링크. 홈의 영업시간을 펼쳐 요일별로 읽고, 정보 탭에서 주차를 읽습니다. '주차 불가'와 '주변 공영주차장 안내'는 원문 그대로 함께 보관하며 가게 주차 가능으로 바꾸지 않습니다. 항목마다 출처 URL과 확인 날짜를 저장합니다.
- **영업시간 정리(2026-10-23):** 현재 상태(영업 전·영업 중·영업 종료·휴무 등)와 무관하게 영업시간 펼치기 버튼을 찾아 누르고(이미 펼쳐져 있으면 그대로 둠), 요일별 행을 읽은 뒤 같은 일정끼리 묶어 표시합니다. 예: `매일 16:00~다음 날 02:00 / 라스트오더 01:00`, `월~목 11:00~21:00 / 라스트오더 20:30` + `금~토 …` + `일요일 정기휴무`. 라스트오더·브레이크타임이 하나라도 다르면 합치지 않고, 비연속 요일은 `월·수·금`처럼 적습니다. 일부 요일만 보이면 '매일'로 넓히지 않고 `미확인 요일: …`을 함께 적습니다. 공휴일·임시휴무 같은 예외는 `별도 안내:`로 따로 보존합니다. 요일별 원자료(화면 표시 그대로)는 화면의 항목 아래와 저장 데이터(`detail.raw`)에 남아 묶음 결과를 검증할 수 있습니다. 이 정리에 AI는 쓰지 않습니다. '영업 상태·라스트오더'(조회 시점 상태)와 '영업시간'(정규 일정)은 별도 항목입니다.
- 못 찾은 항목은 사유를 **로딩 실패 / 추출 실패 / 보안 확인 / 화면에 항목 없음**으로 구분해 표시합니다. 영업시간은 추가로 **펼치기 요소 미발견 / 펼쳤으나 상세 미표시 / 펼쳐졌으나 추출 실패**를 구분합니다. 보안 확인 글자가 있어도 항목 흔적이 있으면 보안 탓으로 돌리지 않습니다.
- 조사한 정보는 매장별로 저장되어 다음 생성에서 재사용됩니다. '매장 정보 조사·재조회' 버튼으로 다시 조회하고, 값을 직접 수정·저장할 수 있습니다(사용자 입력으로 표시). 재조회 때 수정값과 새 값이 다르면 충돌로 표시하고, 30일이 지나면 재조회를 권장합니다.
- 매장이 하나로 구분되지 않을 때만 목록에서 선택합니다. 확인된 값만 본문 기본정보 영역에 들어가고, 못 찾은 값은 확인 목록에 표시됩니다(빈칸 템플릿 없음).
- 초안에는 작성 당시 사용한 매장 정보가 함께 저장되어, 이후 정보를 수정해도 기존 초안은 바뀌지 않습니다.
- **네이버 보안 확인(캡차)이 뜨면** 가려진 항목은 읽지 못하고 미확인으로 남습니다. 프로그램이 자동으로 넘기지 않으니, 전용 Chrome 창에서 직접 보안 확인을 완료한 뒤 재조회하세요.
- 공개 메뉴판 가격과 실제 결제 금액은 구분해서 서술합니다.

## 글 작성 방식과 분량 (2026-10-22)

- 본문은 사진 나열이 아니라 "방문 계기 → 확인된 매장 정보(자료가 있을 때만) → 주문과 실제 경험 → 좋았던 점·아쉬운 점 → 총평" 흐름으로 작성합니다. 자료가 없는 항목은 생략하고, 모든 사진을 쓰지 않을 수 있습니다.
- 사진 설명(캡션)은 필요한 사진에만 짧게 달고, 바로 뒤 문장과 중복되면 확인 목록으로 알려줍니다(자동 수정하지 않음).
- 생일·서비스·할인·단골 같은 표현이 메모에 근거 없이 본문에 있으면 확인 목록으로 알려줍니다.
- 분량 기준은 **본문 공백 제외 글자 수**(사진 표시·제목·태그·확인 목록 제외)이고 기본 최소는 1,000자입니다. 참고 글 분량이 짧아도 최소를 낮추지 않습니다. 목표가 비어 있으면 같은 매장 참고 글 분량(중앙값)을 참고값으로 쓰는데, 엔서포터 글자 수는 한글·영문·숫자 기준이라 기준이 달라 화면에 따로 표시합니다. 편집기 아래에 실제 글자 수가 실시간 표시됩니다.
- 생성 후 코드가 분량을 계산해, 최소 미달이면 **확보된 사실 범위에서 1회 보완 작성**합니다(새 경험·중복·키워드 반복 금지). 그래도 부족하면 실제 글자 수와 사유를 확인 목록에 표시합니다.
- 사진 설명이 바로 뒤 본문과 중복되면 캡션을 자동으로 생략하고 알려줍니다.
- 본인 글 예시는 **선택 사항**입니다. 없으면 기본 후기체(친근하고 담백한 해요체)로 작성하고, 있으면 문장 길이·어미·문단 구성을 반영합니다. '내 기존 글의 말투'를 선택하고 예시가 없어도 오류 없이 기본 후기체로 작성됩니다.
- 추가 작성 규칙이 확보되지 않은 정보(영업정보·위치 등)를 요구하면 그 부분은 적용되지 않고 사유가 확인 목록에 남습니다. 주소·영업시간·주차는 위 매장 정보 자동 조사 경로로 조사하며, 화면에 보이지 않거나 수집되지 않은 값은 추측하지 않습니다.
- 본인 글 예시가 비어 있으면 화면에 안내가 표시됩니다. 예시를 넣어야 '내 말투'가 반영됩니다.


### 버튼을 눌러도 반응이 없을 때
화면 상단이 계속 `연결 확인 중`이면 페이지 스크립트 오류일 수 있습니다. 2026-10-23 영업시간 표시 코드의 줄바꿈 문법 오류를 수정했습니다. 실행 중인 앱은 화면을 새로고침하면 수정본을 읽습니다.

2026-10-23: 검색 결과의 entry/place와 search/검색어/place 링크를 함께 지원합니다. 지역·상호가 모두 맞는 지점이 하나면 자동 조사하고, 구분이 안 되면 이름이 표시된 후보를 선택합니다.

매장 선택지는 매장명·지점과 검색 화면에서 확인된 주소로 표시됩니다. 숫자 ID는 화면에 표시하지 않습니다. 주소가 없으면 미확인 안내가 나오며, 이름 자체가 없는 후보는 선택지에서 제외합니다.
