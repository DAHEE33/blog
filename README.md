# 블로그 작업실 v0.2

사진·방문 메모 → 키워드 후보·제목·목차 → 내 말투의 본문 → 검수·저장으로 이어지는 로컬 프로그램입니다.
Python 3.11 이상이 필요합니다. 추가 Python 패키지는 없습니다.

## 실행

1. ZIP을 새 폴더에 풀고 `start.bat`를 더블클릭합니다. Mac/Linux에서는 `python3 app.py`.
2. 브라우저에서 http://127.0.0.1:8765 가 열립니다. 프로그램 창은 켜두세요.
3. '글을 생성할 AI'에서 실행 방식을 고르고 '실행 방식·말투 저장'을 누릅니다.
4. 사진 또는 사진 폴더, 가게 이름·방문 메모를 입력합니다.
5. 필요하면 목표 키워드와 조사 자료(출처·기준일 포함)를 입력합니다.
6. 초안을 생성하고 키워드 후보·목차·제목·본문·사진 배치를 검수합니다.
7. 본문을 직접 수정하거나 수정 요청으로 재생성합니다. 초안을 저장하거나 사진 포함 HTML을 내려받습니다.

## AI 실행 방식

### Codex CLI

본인 PC에 Codex CLI가 설치되어 있고 터미널에서 `codex` 실행 및 로그인이 완료되어 있어야 합니다.
프로그램은 `codex exec`에 사진과 작성 지침을 전달하고 최종 응답을 받습니다.
읽기 전용 샌드박스를 사용하며 별도 API 키를 요구하지 않습니다.
로그인 계정·버전·사용 한도에 따라 실행이 실패할 수 있습니다. 무료·무제한을 뜻하지 않습니다.

### Claude Code CLI

본인 PC에 Claude Code가 설치되어 있고 터미널에서 `claude` 실행 및 로그인이 완료되어 있어야 합니다.
`--restricted`를 지원하는 버전(v2.1.248 이상)이 필요합니다.
임시 사진 폴더에서 Read 도구만 사용하도록 호출합니다. 쉘·편집·MCP 도구는 허용하지 않습니다.
임시 폴더 안의 사진을 읽고 JSON 본문을 반환하도록 요청합니다.
실제 계정에서 사진 읽기와 로그인·사용량이 정상인지 실행 확인이 필요합니다.

두 CLI 방식 모두 사진·메모·말투 예시를 선택한 서비스로 전달합니다.
프로그램에서 API 방식용 키를 CLI에 넘기지 않도록 주요 API 키 환경변수를 제거한 별도 환경으로 실행합니다.
API로 자동 전환하지 않습니다. CLI에 저장된 인증·조직 설정 및 사용 한도·과금 정책이 적용됩니다.
CLI 설치·로그인 방법은 각 공식 문서를 참고하세요.

- Codex: https://developers.openai.com/codex/noninteractive
- Claude Code: https://code.claude.com/docs/en/headless

### Claude API (선택)

`config.example.json`을 복사하여 같은 폴더에 `config.json`으로 저장합니다.
`api_key`에 Anthropic API 키, `model`에 계정에서 사용 가능한 이미지 입력 지원 Claude 모델 ID를 입력하고 다시 실행합니다.
환경변수 ANTHROPIC_API_KEY / ANTHROPIC_MODEL도 지원합니다. API 사용료는 별도입니다.
키는 화면에 표시하지 않습니다. config.json은 평문이므로 본인 PC에서만 보관하고 채팅·공유 파일에 넣지 마세요.

## 저장된 말투 = 프롬프트·예시 적용

- 말투 유형과 기존 글 1~3편을 저장하면 매번 자동으로 전달합니다.
- 참고 글에서 문장 길이·어미·문단 구성을 적용하고 장소·경험은 가져오지 않도록 지시합니다.
- 모델 가중치를 바꾸는 파인튜닝은 하지 않습니다.
- 키워드 후보는 AI 아이디어입니다. 실제 검색량·경쟁도·인기를 자동 조회하는 기능은 없습니다.
- 검색광고 키워드도구에서 확인한 자료를 직접 입력하면 그 자료를 바탕으로 작성하도록 요청합니다.
- 제목·목차·말투 점검은 한 번의 생성 안에서 요청합니다. 별도 조사·검수 모델을 따로 실행하지 않습니다.
- 유행 추적·검색 상위 노출·수익 보장 기능은 없습니다.

## 사진과 초안

- 사진은 최대 20장. JPG·PNG·WebP 지원. HEIC는 JPG로 변환해 주세요.
- 브라우저가 긴 변 1600px 이하 JPEG로 변환합니다. 원본 파일은 수정하지 않습니다.
- 설정·초안·축소 사진은 `data/studio.sqlite3`에 저장됩니다. 이 파일을 백업하세요.
- 초안 생성 성공 시 자동 저장하고 다시 열 수 있습니다. 재생성·수동 저장은 현재 초안을 덮어씁니다. 수정 이력 기능은 없습니다.
- 최종 게시와 사실 확인은 직접 합니다. 네이버 자동 입력·게시와 폴더 자동 감시·예약 실행은 아직 없습니다.

## 기존 v0.1 사용 시

기존 프로그램을 종료하고 새 버전을 다른 폴더에 풉니다. 기존 `data` 폴더를 새 프로그램 폴더 안으로 복사하면 기존 초안을 이어서 볼 수 있습니다.
기존 API 설정을 계속 쓰려면 config.json도 본인 PC 안에서 복사하고 화면에서 Claude API 방식을 선택하세요.

## 검증 범위

`python -m unittest discover -s tests -v`
HTTP 저장·다시 열기·접근 토큰, API 요청 및 오류, CLI 명령·이미지 전달·임시 파일 정리·키 격리·자동 API 전환 방지를 8개 테스트로 검증했습니다.
외부 AI 응답과 CLI 실행은 모의 응답입니다. 이 환경에 Codex/Claude CLI와 사용자 인증이 없어 실제 생성은 검증하지 못했습니다.
브라우저 설치도 완료하지 못해 화면 클릭·시각 검증은 아직 하지 못했습니다.

다른 가이드의 비공개 프롬프트는 포함하지 않았습니다. 이 프로그램의 작성 지침은 별도로 작성했습니다.
