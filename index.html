보관한 초안

사진과 방문 메모로 초안을 만듭니다. 최종 확인과 게시는 직접 진행해 주세요.

01. 사진과 방문 경험

사진은 브라우저에서 축소됩니다. 원본 파일은 수정하지 않습니다.
전용 Chrome이 닫혀 있으면 기존 프로필로 자동 실행됩니다(최초 1회 엔서포터 설치 필요). 가게 이름 검색(같은 매장 글)과 목표 키워드 검색(키워드당 최대 3글)을 분리해 각각 엔서포터 단어 분석을 읽습니다. 블로그 API를 사용하지 않으며, 결과를 선택한 AI에 전달합니다. 말투는 내 설정을 사용합니다.
02. 저장해두고 쓰는 말투
기준: 본문 공백 제외(사진 표시·제목·태그 제외). 목표가 비어 있으면 같은 매장 참고 글 분량(중앙값)을 참고값으로 전달하되 최소 분량은 낮추지 않습니다. 최소 미달이면 확보한 사실 범위에서 1회 보완 작성하고, 그래도 부족하면 사유를 확인 목록에 표시합니다. 분량을 채우려고 경험을 만들지 않습니다.

생성할 때 사진·메모·말투 예시를 선택한 AI로 보냅니다. CLI는 로그인 계정의 사용 한도·과금 정책이 적용되며 API 방식은 별도 API 요금이 적용됩니다.

03. 초안 검수

사진과 메모를 넣고 초안을 생성해 주세요. 생성 전에 AI 실행 방식을 선택하고 저장해 주세요. 키워드 후보는 실제 검색량 조회 결과가 아닙니다.
