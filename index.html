02. 저장해두고 쓰는 말투

생성할 때 사진·메모·말투 예시를 선택한 AI로 보냅니다. CLI는 로그인 계정의 사용 한도·과금 정책이 적용되며 API 방식은 별도 API 요금이 적용됩니다.
